Circular Queue (Ring Buffer)

nextIndex = (currentIndex + 1) % capacity

A Circular Queue overcomes linear array memory wastage by logically connecting the last position back to the first. Critical Rule: A dedicated size counter is maintained to distinguish between the EMPTY state (size == 0) and FULL state (size == capacity).

Fixed Array Implementation & Limitation Demo

Fixed Buffer Indices [0 .. n-1]

In a naive linear array implementation, both front and rear move monotonically to the right. Once rear == capacity - 1, no more elements can be enqueued—even if multiple elements have been dequeued from the front! This is called False Overflow.

Array capacity = 6. Slots are indexed 0 to 5.
FRONT Pointer: -1
REAR Pointer: -1
Why Linear Array Queue is Inefficient:

When elements are dequeued, front increments, leaving inactive slots at the beginning of the array. When rear reaches index n - 1, the queue claims to be full even though vacant slots exist at index 0, 1, etc.! Shifting elements to index 0 requires O(N) time. The solution is the Circular Queue, which wraps around in O(1) time.

Linked List Implementation (Dynamic Nodes)

FRONT -> [Data|Next] -> NULL <- REAR

A Linked List implementation provides dynamic capacity with strictly O(1) Enqueue and Dequeue operations. When the last remaining node is dequeued, both FRONT and REAR safely become NULL.
