Peek Operation

The peek() or top() operation returns the value of the top element without removing it from the stack.

Is Empty Operation

isEmpty() checks whether the stack contains 0 elements. Under an array representation, this condition is tested as top == -1.

Algorithm Definition
bool isEmpty() {
    return (top == -1);
}

Postfix Expression Evaluation (Reverse Polish Notation)

In Postfix notation, operators follow their operands (e.g. 5 2 3 * +). It is evaluated Left to Right using an operand stack.
Rule: When operator is encountered, pop right operand b, then left operand a, compute a op b, and push result.

Prefix Expression Evaluation (Polish Notation)

In Prefix notation, operators precede their operands (e.g. + 5 * 2 3). Prefix is evaluated Right to Left.
Critical Operand Order Rule: When operator is encountered, first pop = Left operand (op1), and second pop = Right operand (op2). Then compute op1 op op2 and push result back to stack.

Array-Based Stack

Stack implemented using a fixed-size contiguous array arr[MAX]. The variable top points to the index of the topmost item (starts at -1 when empty).

Contiguous Memory Slots (MAX = 6):
Variable top: top = -1
Initialized empty stack: top = -1.

Array Implementation Code

// C++ Fixed-Array Stack #define MAX 6 int arr[MAX]; int top = -1; bool push(int x) { if (top >= MAX - 1) { cout << "Stack Overflow!\n"; return false; } arr[++top] = x; return true; } int pop() { if (top < 0) { cout << "Stack Underflow!\n"; return -1; } return arr[top--]; } int peek() { if (top < 0) return -1; return arr[top]; }
// Java Fixed-Array Stack class ArrayStack { static final int MAX = 6; int top = -1; int arr[] = new int[MAX]; boolean push(int x) { if (top >= MAX - 1) { System.out.println("Stack Overflow"); return false; } arr[++top] = x; return true; } int pop() { if (top < 0) { System.out.println("Stack Underflow"); return -1; } return arr[top--]; } int peek() { return (top < 0) ? -1 : arr[top]; } }
# Python Fixed-Array Stack class ArrayStack: def __init__(self, capacity=6): self.capacity = capacity self.arr = [None] * capacity self.top = -1 def push(self, val): if self.top >= self.capacity - 1: raise Exception("Stack Overflow") self.top += 1 self.arr[self.top] = val def pop(self): if self.top < 0: raise Exception("Stack Underflow") val = self.arr[self.top] self.top -= 1 return val def peek(self): return self.arr[self.top] if self.top >= 0 else None

Linked List-Based Stack

Stack implemented dynamically where each node stores data and a next pointer. TOP always points to the head node. Push and Pop occur in O(1) time at the head.

Dynamic Node Chain:
Pointer Mutation Steps
Ready. Nodes are linked starting from TOP down to NULL.

Linked List Implementation Code

// C++ Linked List Stack struct Node { int data; Node* next; Node(int val) : data(val), next(nullptr) {} }; Node* top = nullptr; void push(int x) { Node* newNode = new Node(x); newNode->next = top; top = newNode; } int pop() { if (top == nullptr) { cout << "Stack Underflow!\n"; return -1; } Node* temp = top; int val = temp->data; top = top->next; delete temp; return val; }
// Java Linked List Stack class Node { int data; Node next; Node(int val) { this.data = val; this.next = null; } } class LinkedListStack { private Node top = null; public void push(int x) { Node newNode = new Node(x); newNode.next = top; top = newNode; } public int pop() { if (top == null) { System.out.println("Underflow"); return -1; } int val = top.data; top = top.next; return val; } }
# Python Linked List Stack class Node: def __init__(self, data): self.data = data self.next = None class LinkedListStack: def __init__(self): self.top = None def push(self, val): new_node = Node(val) new_node.next = self.top self.top = new_node def pop(self): if self.top is None: raise Exception("Stack Underflow") val = self.top.data self.top = self.top.next return val
